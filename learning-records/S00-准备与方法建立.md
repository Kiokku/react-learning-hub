## 1. 已形成的稳定理解

- 一个 Lesson 只有完成理解、闭卷实现、行为测试、偏差复盘和面试表达后，才能标记为“已完成”；阶段还需要单独通过闭卷实现、关键行为测试和两轮追问。
- 学习仓库保存路线、Notes、进度和证据索引；`mini-react18` 仓库保存实现、测试与 Demo。学习仓库不复制完整实现代码。
- pnpm workspace 负责组织和链接本地包；`peerDependencies` 约束包发布后由宿主提供的依赖，不能替代 workspace 的本地联调。
- ESLint、TypeScript、Husky、commitlint、Vitest 和 Rollup 解决不同问题，不能用其中一个检查替代整条工程验证链路。
- 当前项目由 ESLint 同时承担代码规范和代码风格检查，不引入 Prettier。
- Rollup 当前负责库包构建；以后需要浏览器 Demo 时，可以增加 Demo 入口，不必替换已经验证的库构建链路。

## 4. 当前边界

- 阶段 0 只覆盖学习方法和工程基础，不提前学习 `react`、`react-dom`、`react-reconciler` 的内部职责；这些内容从阶段 1 的 JSX Runtime 开始。
